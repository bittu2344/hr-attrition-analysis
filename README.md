# 👥 HR Employee Attrition Analysis

**Author:** Bittu Kumar | Data Analyst
**Tools:** Python | Pandas | Seaborn | Matplotlib | Excel

## 🎯 Project Overview
Explored IBM HR Analytics dataset (1,470 employees) to uncover key factors driving attrition. Generated **15+ visualizations** revealing employees aged 25–35 in overtime roles face **40% higher attrition**.

## 🔍 Key Findings
- Overall Attrition Rate: ~16%
- High-Risk Group: Age 25–35 + Overtime = 40% higher attrition
- Top Attrition Department: Sales
- Employees who left earned ₹2,000–₹3,000 less per month than those who stayed
- Poor Work-Life Balance strongly correlates with attrition

## ⚙️ How to Run
1. Download IBM HR dataset from Kaggle
2. Save as `WA_Fn-UseC_-HR-Employee-Attrition.csv`
3. Install: `pip install pandas numpy matplotlib seaborn`
4. Run: `python hr_attrition_analysis.py`
